# llm-eval-promptfoo

Hands-on learning of LLM evaluation with [Promptfoo](https://www.promptfoo.dev/).

## Goal

Build practical experience in testing prompts and models: write test cases, run them, compare prompts and models, and record metrics and conclusions.

## What this repository will contain

- Test configurations (`promptfooconfig.yaml`) for each experiment
- Results: pass rates and before/after comparisons
- Short conclusions: how a change in a prompt or a model affected the answers

## Status

Work in progress. Experiments are added step by step.

## Notes

- API keys are never stored in this repository; they are read from environment variables.
- Languages of test cases: English, Ukrainian, Russian.
